# 靜謐森林屋 · 排班打卡

三個人共用的拍照打卡 + 排班小工具。整個網站就是 `index.html` 這一個檔案，沒有後端、不用註冊、不用資料庫。

**線上版：** https://peiyunchiu.github.io/forest-shift-clock/
**用 LINE 打卡：** 設定步驟看 [SETUP-LINE.md](SETUP-LINE.md)

## 怎麼打開

- **手機（推薦，因為要拍照）**：開上面那個網址，用 Safari／Chrome 的「加入主畫面」，用起來就像 App。
- **電腦**：一樣開網址就好。想離線用就下載 `index.html`，右鍵 →「打開檔案的應用程式」→ **Chrome**（Safari 直接開本機檔會擋住網頁存資料，開起來會跳紅色警告）。

> ⚠️ 沒接 LINE／雲端時，網址版和本機檔案版是**兩個各自獨立的資料空間**，紀錄不會互通。接上雲端後就都看同一份。

## 工時規則

每天一律上 **7 小時**。折備品**不當天扣**，而是存進帳戶，之後自己挑一天抵。

| 情況 | 當日應上班 |
|---|---|
| 一般日 | 7 小時 |
| 當晚有折備品 | 還是 7 小時，另外 **＋1 小時進帳戶**（時數可自己改） |
| 休假日去折備品 | 應上班還是 0，但一樣 **＋時數進帳戶** |
| 用帳戶抵 2 小時 | 5 小時 |
| 用帳戶抵滿 7 小時 | 0 小時（等於整天休） |
| 排班標記休假 | 0 小時，不算缺勤 |

> 補登沒有時間限制，多久以前的日子都補得回來。

- 實際工時 = 下班 − 上班 − 休息分鐘（跨夜到隔天凌晨會自動算對）
- 超過應上班 → 加班；不到 → 不足
- 帳戶餘額 = 累積折備品時數 − 已抵用時數。抵超過餘額會跳提醒，硬要抵就變負的
- 數字要改（一次折備品算 1.5 小時、或改成 8 小時制）到「設定 → 工時規則」自己調

## 五個分頁

1. **打卡** — 選人 → 上班／下班打卡（會開相機拍照存證）。當晚有折備品勾一下就 ＋1 小時入帳，卡片上直接看得到自己還有幾小時可抵。忘了拍照可以按「不拍照直接打卡」；忘了打卡按「手動修改今天」補，**以前的日子按「補登以前的」**。
2. **排班表** — 月曆。點某一天可排三個人的班（幾點上、當晚要不要折備品、休假），每個人旁邊的 **補打卡** 可以直接補那天的實際上下班時間。下面「快速批次排班」可以一次排一整段日期。橘色＝當晚要折備品，灰色＝休假，綠框＝已經打完下班卡。
3. **紀錄** — 依月份／人查歷史，看得到當天的打卡照片，也能修改或刪除。上方的 **＋ 補登以前的打卡** 可以選人、選任何一天補上下班時間。
4. **統計** — 每人當月：實際工時、應上班工時、加班合計、不足合計、本月折備品入帳、本月抵用／帳戶剩餘 + 每日明細，可匯出 CSV 給 Excel。
5. **折抵帳戶** — 三個人各自的折備品時數餘額（累積／已抵／可抵）。
   - **＋ 補登折備品**：選人、選日期、填折了幾小時。**休假日去折、忘了勾的日子、折超過一小時，全部用這個補**，不需要那天有打卡。
   - **用時數抵一天**：選人、選日期、填要抵幾小時。抵滿 7 小時＝整天休。
   - 每一筆入帳與抵用都列在「進出明細」，按「改」可以回頭修正；時數填 0 就是取消那天的紀錄。
6. **設定** — 改工時規則、改員工名字、備份／還原、清空。

## 資料存在哪（重要）

紀錄和照片都存在**打卡那台裝置的瀏覽器裡**，關掉網頁不會不見，但：

- 換手機、換瀏覽器、清瀏覽器資料 → 資料不會跟著走
- 所以三個人請**固定用同一台裝置打卡**（例如民宿放一支手機或 iPad 當打卡機）
- **每個月到「設定 → 下載備份檔」存一份**（含照片）。換裝置時用「還原備份」搬過去

想要三個人各自的手機都同步同一份資料，就得再接雲端資料庫，那是另一階段的工程，跟 Chloe 說一聲再做。

## 用 LINE 打卡（選配）

接上 LINE 官方帳號後，在 LINE 按一下就能打卡（還能拍照存證），三個人的紀錄匯到同一份 `data/records.json`，網站讀的也是這一份。

```
LINE 按「上班」→ Apps Script 收到 → 寫進 GitHub → 網站顯示
         └→ 跳「📷 拍照」→ 照片存進 Google Drive → 網站也看得到
```

- 設定步驟：[SETUP-LINE.md](SETUP-LINE.md)
- 機器人程式碼：[apps-script/Code.gs](apps-script/Code.gs)
- LINE 只能打今天的卡；以前的日子到網站補登
- 沒設定也沒關係，網站本身照常能用，資料就存在各自裝置
